# AI 결과창 추출 실험

Java 21 독립 Gradle 프로젝트입니다. 백엔드·프런트 코드는 사용하거나 수정하지 않습니다.

## 실행

저장소 루트의 `.env` 또는 환경변수에 `GEMINI_API_KEY`, `GEMINI_MODEL`을 설정합니다.
환경변수가 우선하며 키는 출력하지 않습니다.

이 폴더에서 실행합니다.

```powershell
.\gradlew.bat test
.\gradlew.bat run
```

유닉스에서는 `./gradlew test`, `./gradlew run`입니다.
최초 의존성 해석에는 네트워크가 필요합니다. 단위 테스트 본문은 네트워크·샘플·키를 사용하지 않습니다.

## 입력과 결과

- 입력: 저장소 루트 `samples/*.png`, `samples/ground-truth.json`.
- 결과: `out/report.md`, `out/report.json`, `out/crops/`.
- 공식 아이콘 캐시: `cache/ddragon/{버전}/`. 실행마다 최신 버전을 조회하며 리포트에 고정합니다.
- JSON 보고서에는 닉네임이 포함됩니다. 출력·캐시·샘플은 Git 제외입니다.
- 정답지는 `samples` 배열 안의 `file/result/date/duration/top/bottom`이며, 팀의 `kda/gold/rows`,
  행의 `nick/kda/cs/gold`를 비교합니다. 추가 메타데이터는 평가하지 않습니다.
- 실패 이미지도 정답 필드 분모에 포함합니다. 정답이 없는 이미지는 별도로 표시하며 정확도에서 제외합니다.
- 챔피언·밴 정확도는 `run`이 아니라 `tune`이 계산합니다. 정답지 행의 `champion`, 팀의 `bans`(Data Dragon id)를 씁니다.
  `./gradlew tune`은 Gemini를 다시 부르지 않고 마지막 `run`이 남긴 `out/crops/`로 비교 설정별 정확도를 출력합니다.
- 닉네임 정확 일치와 접두부 정규화 일치는 별도입니다. 정규화는 NFKC·공백 제거·말줄임 제거 후,
  말줄임된 인식값에만 정답의 70% 이상 접두부 일치를 허용합니다. 선수 자동 연결 구현은 M2 범위입니다.

## 재시도와 시간

이미지 사이 5초 대기, API 요청 제한 120초, 최대 4회 시도입니다.
SDK 내부 재시도는 끄고 HTTP 408·429·5xx만 5초·10초·20초에 0~999ms 무작위 지연을 더해 재시도합니다.
실패 응답 본문이나 예외 메시지는 저장하지 않고 HTTP 상태·예외 유형만 기록합니다.
API 지연에는 백오프가 포함되며 전체 이미지 지연에는 이미지 읽기·매칭도 포함됩니다.
공식 아이콘 최초 다운로드와 이미지 사이 대기는 이미지 지연에서 제외됩니다.

## 현재 검증 상태

2026-10-16 실행 환경의 외부 소켓 권한 제한으로 Maven 의존성 다운로드가 실패했습니다.
정규 `gradlew test`와 `gradlew run`은 의존성 해석에서 막혔고, Gemini 요청과 샘플 3장 실측은 수행되지 않았습니다.
캐시의 Jackson 2.18.0·JUnit API 5.13.2로 순수 로직 테스트 메서드 8개를 별도 실행해 통과했습니다.
이 결과는 정규 Gradle 테스트 성공이나 선언 의존성 전체 빌드 검증을 뜻하지 않습니다.
실측 정확도·지연·429 빈도는 아직 없습니다. M0 완료 조건은 미충족입니다.

설계 판단은 [ADR 003](../../docs/adr/003-extraction-approach.md)을 참고합니다.
