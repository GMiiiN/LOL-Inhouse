# ADR 002. 비밀값은 루트 .env 한 곳, 결과창 샘플은 저장소 밖

- 날짜: 2026-10-16
- 상태: 채택

## 배경
Gemini API 키, DB 비밀번호, 담당자 계정이 필요하다. 결과창 샘플에는 친구들의 게임 닉네임이 들어 있다. GitHub 저장소는 공개일 수 있다.

## 결정
- 로컬 비밀값은 저장소 루트 `.env` 하나에 둔다. git에서 제외하고 견본 `.env.example`만 커밋한다.
- docker compose(`--env-file`), Spring(`spring.config.import`), 실험 도구가 모두 같은 `.env`를 읽는다.
- 운영에서는 같은 이름의 환경변수/시크릿 저장소로 주입한다(M7).
- 결과창 샘플과 정답지는 `samples/`(git 제외)에 둔다.

## 대안
- 모듈별 설정 파일(application-local.yml 등)에 비밀값: 값이 여러 곳에 흩어져 불일치·유출 위험이 커진다.
- 샘플을 저장소에 포함: 테스트 재현은 쉬우나 닉네임 노출. 테스트에는 숫자만 담은 픽스처를 코드로 만들어 쓴다.

## 결과
새 개발 환경에서는 `.env.example`을 복사해 값을 채워야 한다. CI는 `.env` 없이 돌아야 하므로 테스트가 실제 키에 의존하지 않게 만든다.
