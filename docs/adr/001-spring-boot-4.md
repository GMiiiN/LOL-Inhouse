# ADR 001. Spring Boot 3.5 대신 4.1.1 사용

- 날짜: 2026-10-16
- 상태: 채택

## 배경
구현 계획은 학습 자료(Boot 3 기반 강의)와 맞추려고 Spring Boot 3.5.x를 정했다. 그러나 M1 착수 시점에 Spring Initializr가 제공하는 버전은 4.0.8, 4.1.1(정식)과 스냅샷·마일스톤뿐이었고 3.5는 목록에서 빠져 있었다.

## 결정
정식 최신인 **Spring Boot 4.1.1**로 시작한다.

## 대안
- **3.5.x를 수동 지정**: Maven Central에는 남아 있지만, 목록에서 빠졌다는 것은 무료 지원 종료가 가깝거나 끝났다는 뜻이다. 새 서비스를 보안 패치가 끊기는 버전으로 시작하면 운영 중 업그레이드 부담이 바로 생긴다.
- **4.0.x**: 4.1보다 먼저 나와 지원 종료도 먼저 온다.

## 결과
- 강의(Boot 3)와 차이가 생긴다. 핵심 개념(DI, MVC, JPA, Security 필터 체인)은 같고, 의존성 이름·일부 설정 키·라이브러리 세대(예: Jackson)가 다를 수 있다. 실제로 마주친 차이는 `docs/study/02-backend-skeleton.md`에 기록한다.
- 의존 라이브러리(Testcontainers, AWS SDK, Google Gen AI SDK)는 Boot 버전과 독립적이라 영향이 작다.
