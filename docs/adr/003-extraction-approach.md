# ADR 003. 결과창 추출: Gemini는 읽기·위치, 챔피언은 공식 아이콘 비교

- 날짜: 2026-10-16
- 상태: 채택(샘플 3장 실측 기반, 새 샘플로 재검증 필요)

## 배경
결과창 스크린샷 1장에서 세트 기록(승패·날짜·시간·10명의 닉네임·K/D/A·CS·골드·챔피언, 밴 10개)을 뽑아야 한다. 캡처 범위가 매번 달라 고정 좌표는 쓸 수 없고, 결과창에는 챔피언 이름이 글자로 없다.

## 결정
1. **Gemini(`gemini-3.8-flash`, 무료 등급)**에 JSON 스키마를 강제해 숫자·글자·날짜·시간·승패와 초상화·밴 아이콘의 **위치 박스**만 받는다. 모델명은 `.env`의 `GEMINI_MODEL`로 바꿀 수 있다.
2. 챔피언은 박스로 잘라 **Data Dragon 공식 아이콘과 이미지 비교**로 정한다. 픽과 밴은 설정을 분리한다.
   - 픽(`IconMatcher.PICK`): 원형 마스크, 공식 아이콘 8% 확대, 색 0.7 + 무늬 0.3
   - 밴(`IconMatcher.BAN`): 잘라낸 이미지 테두리 12% 제거, 사선 띠 무시, 색 비교
3. 무료 등급 503/429에 대비해 지수 백오프 재시도를 둔다.

## 대안
- 모델에게 챔피언 이름까지 요청: 읽기 오류와 지식 오류가 섞임. 밴 정확도를 올릴 보조 신호로는 후속 실험 가치가 있음.
- 고정 좌표: 캡처 범위가 달라지면 깨짐.
- 유료 모델(OpenAI 등): 무료 등급으로 숫자 100%가 나와 지금은 불필요.

## 결과 (샘플 3장, 2026-10-16)
| 항목 | 결과 |
|---|---|
| 승패·날짜·시간 / 팀 합계 / 선수 숫자 | 3/3 / 6/6 / 30/30 |
| 닉네임 | 26/30 (모두 한 글자 오인식) |
| 픽 | 29/29 (튜닝 전 28/29) |
| 밴 | 20/30, 3위 안 23/30 (튜닝 전 5/30) |
| 지연 | 약 23초(재시도 없음) ~ 66초(503 재시도 3회) |
| 2차 재실행(같은 3장) | 닉네임 27/30, 픽 29/29, 밴 17/30(3위 안 23/30), 지연 43~89초(503·429 재시도) |

픽·밴 수치는 같은 3장으로 설정을 고르고 평가한 값이라 낙관적이다. 또 같은 이미지도 실행마다 Gemini의 박스·닉네임이 조금씩 달라져 밴 1위 정확도가 17~20/30 사이로 흔들렸다. 밴은 "1위 자동 확정"이 아니라 "상위 3개 중 선택"으로 설계한다.

## M4 반영
- 숫자·경기 정보는 자동 채움(팀 합계 검사 유지).
- 닉네임은 등록 닉네임 유사도 매칭으로 보정, 처음 보는 닉네임 강조.
- 픽은 자동 채움 + 아이콘으로 확인.
- 밴은 상위 3개 후보 + 검색으로 담당자가 확정, 1·2순위 차이가 작으면 강조.
- 장당 20초 이상이므로 진행 표시 필요.
- 새 결과창이 모이면 같은 설정으로 재측정하고 이 ADR을 갱신한다.
